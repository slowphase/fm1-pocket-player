    What a simulator can and can't tell you
    

      
The sound and the picture come from the firmware's own code, compiled for the browser, driven one device millisecond at a time with the same 44.1 kHz audio blocks and 15 ms frames the FM-1 runs. Saves go to a flash image kept in this browser, so a firmware remembers its settings between visits.

      
What it can't show: how hard the FM-1's own processor is working, how the speaker sounds, and how the keys and encoders feel. An .rfm1 is a firmware's host build, so code that only runs on the chip (its drivers, Bluetooth, USB) is not in it; an original .fwsc package runs on an emulation of the chip instead. Try a firmware here, then flash the device build with its own installer. This simulator is open source: fm1-browser-simulator on GitHub.
